# backtest-test

Backtest di una strategia SMA 50/200 su BTC-USD (ultimi 3 anni, con 200 giorni
di riscaldamento per la SMA 200) confrontata con buy & hold.

Fee: 0,1% per operazione. Segnale a chiusura del giorno t, eseguito a chiusura
del giorno t+1 (nessun look-ahead).

Istruzioni e risultati: vedi le sezioni aggiunte dal task di documentazione.
